# To-Do List

## Project Description

The To-Do List is a simple command-line application developed in Python. It helps users organize their daily tasks by allowing them to add, view, and remove tasks easily.

## Features

- Add new tasks
- View all tasks
- Remove completed tasks
- Menu-driven interface
- Beginner-friendly code

## Technologies Used

- Python 3

## How to Run

1. Save the file as `main.py`
2. Open the terminal.
3. Run:

```bash
python main.py
```
